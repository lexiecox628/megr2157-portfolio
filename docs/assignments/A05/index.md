# A5 – Bracket Design

## Objective

In this assignment I had to design a bracket that withstand the forces acting upon it. The bracket can be split up into 5 different features, each with there own stress analysis and free body diagrams. 

For this assignment I chose the material to be aluminum 6061-T6 and a force of 600 lbf.

## Lessons Leanred

In my observations the stress dimensions were always larger values than the stiffness. Therefore the stress dimensions determined which final size I used. 

One value that carried into a later value was the base length I chose for feature 3. It was the same base length that I used in feature 4 because they were calculating two features of the same area. If I didn't catch this and I used a different value my sketches would contradict some values. 

One assumption I made was that feature 3 was fixed. If I did not assume it was fixed the beam would have more forces and moments acting against it and it would have affected my calculations.
