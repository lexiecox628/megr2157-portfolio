## Communicate

A lesson I learned while completing this assignment is some of the trade-offs you have to make to make a more reliable design. For example when making the shafts the allowable diameter was only 0.141 in. However, a more suitable diameter would be 0.25 in. This is because you want to factor in outside factors and forces that will be applied to it. Therefor, a bit more material will make the overall design more secure.
